## Detail Proyek

**Data Visualization Portfolio** merupakan repositori terpusat yang menghimpun berbagai implementasi proyek visualisasi data dan dashboard **Business Intelligence (BI)** interaktif. Portofolio ini dirancang untuk mentransformasikan data mentah operasional menjadi wawasan bisnis (*actionable business insights*) melalui pendekatan *data storytelling*, pemodelan data relasional, kalkulasi metrik lanjutan, serta penyajian visual yang elegan dan mudah dipahami oleh stakeholder bisnis maupun pengambil keputusan.

---

### Sub-Modul & Spesifikasi Proyek

Setiap platform diimplementasikan ke dalam sub-folder repositori khusus dengan fokus analitik tersendiri:

#### 1. [Microsoft Power BI](https://github.com/irfanwdtr/dashboard/tree/main/power-BI)
- **Fokus Rekayasa**: Pemodelan data relasional (*Star Schema*), pembuatan *calculated columns* dan *measures* dinamis menggunakan formula **DAX (Data Analysis Expressions)**, serta perancangan hierarki filter interaktif.
- **Kapabilitas Utama**:
  - Executive KPI summary cards (Total Pendapatan, Margin Keuntungan, Pertumbuhan MoM/YoY).
  - Mekanisme *cross-filtering* dan *drill-down* antar visualisasi (berdasarkan wilayah, kategori produk, dan periode waktu).
  - Optimasi *data refresh* dan tata letak pelaporan modern berstandar enterprise.

#### 2. [Metabase](https://github.com/irfanwdtr/dashboard/tree/main/Metabase)
- **Fokus Rekayasa**: Eksplorasi analitik langsung di atas basis data relasional (PostgreSQL / MySQL) menggunakan kombinasi **Native SQL Editor** dan **Visual Query Builder**.
- **Kapabilitas Utama**:
  - Dashboard operasional real-time untuk pemantauan metrik transaksi dan aktivitas harian.
  - Parameter filter dinamis (tanggal, status transaksi, segmen pelanggan) yang terhubung langsung ke query SQL.
  - Penyusunan *collection & permissions* terstruktur untuk kemudahan *sharing* laporan ke tim operasional.

#### 3. [Tableau](https://github.com/irfanwdtr/dashboard/tree/main/Tableau)
- **Fokus Rekayasa**: *Data storytelling* mendalam, analisis komparasi multi-variabel, pemanfaatan kalkulasi tingkat lanjut menggunakan **LOD (Level of Detail Expressions: FIXED, INCLUDE, EXCLUDE)**, serta analisis spasial.
- **Kapabilitas Utama**:
  - Visualisasi tren dinamis menggunakan *dual-axis charts* dan *heatmaps*.
  - *Dynamic Parameters* untuk simulasi skenario bisnis dan analisis *what-if*.
  - Desain dashboard responsif dengan navigasi visual yang interaktif.

#### 4. [Google Looker Studio](https://github.com/irfanwdtr/dashboard/tree/main/GoogleLookerStudio)
- **Fokus Rekayasa**: Perancangan dashboard berbasis cloud yang terintegrasi secara mulus dengan berbagai sumber data Google (Google Sheets, BigQuery) dan database SQL eksternal.
- **Kapabilitas Utama**:
  - *Data Blending* lintas sumber data untuk menggabungkan metrik operasional dan pemasaran.
  - Pembuatan *calculated fields* kustom untuk segmentasi performa bisnis.
  - Pelaporan otomatis berbasis cloud yang mudah dibagikan (*collaborative reporting*) dengan akses hak kontrol aman.
